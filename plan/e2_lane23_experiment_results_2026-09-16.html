E2 补充实验：Lane 数扫描（E2-3 / E2-2）

日期：2026-09-16 ｜ 补充自：plan/e2_five_lane_experiment_results_2026-09-13.html（E2-5 主实验）｜ 范围：max-3 / max-2 调度 + E2 条带化编码 + bit-exact 往返 + 穷举 + 三池容量 + 功能级 RTL 逐周期回归（每池独立 top/tb，正+反序）。全部通过。

实验设定（与 E2-5 的唯一差异）：维持 E2 条带化存储核心方案不变（每周期 5-bit mask、phase 轮转条带化、隐式 EOP、hold 输出语义），目标操作池不变（BERT 4 / SD-UNet 5 / LLaMA 3，共 12 个程序，每程序沿用 max-5 选定的调度 mode）。只把调度器最大并发槽位改为 3 和 2，对应 3 条 / 2 条共享物理 lane（phase 模 3 / 模 2）。
一句话结论：E2-3 / E2-2 功能正确性全部验证通过，但在统一最大物理配置下 E2-5（1,556,480 bit）仍最优：E2-3 = 1,835,008 bit（E2-5 的 117.9%）、E2-2 = 2,392,064 bit（153.7%）。原因是有效 payload 信息量守恒（LLaMA 池 33,104 个 34-bit 事件与调度无关），E2 的 phase 条带化已把 lane 长度均衡到相差 ≤1；减少 lane 数只能加深单条 lane，2 的幂深度填充浪费反而更大（payload 利用率：E2-5 80.8% → E2-3 67.3% → E2-2 50.5%）。lane 数不宜低于逻辑槽数。性能侧：max-3 几乎无代价（多数程序 T3=T5），max-2 最差 +4.6%。

2. 软件验证

  • bit-exact 往返：12 程序 × 2 种 lane 数全部通过（编码→软件解码→逐周期逐 slot 逐 bit 比对原始调度）。
  • payload 总量不变性：每程序有效 slot 事件数在 max-5/3/2 下完全一致（DAG 固定，调度只改变发射时刻）——这是容量结论的关键前提。
  • mask×phase 穷举：E2-3 合法 26 mask（popcount≤3）× 3 phase = 78/78 态通过；E2-2 合法 16 mask（popcount≤2）× 2 phase = 32/32 态通过（lane 读取数==popcount、slot↔lane 双射、phase_next 在界内）。E2-5 原 160 态检查同步复跑通过。
  • w=5 交叉核对：本脚本重算的 E2-5 三池容量与统一最大配置同 plan Table 5 / Table 6 全部 MATCH。

7. 结论与论文用法

  • E2 条带化方案对 lane 数 2/3/5 均功能正确（软件穷举 + RTL 逐周期回归），方案本身可参数化。
  • 统一最大配置下 E2-5 是最优点：lane 数 = 逻辑槽数时 payload 利用率最高（80.8%）；lane 数降至 3/2 后，信息量守恒 + 2 的幂填充使总容量升至 117.9% / 153.7%。这从反方向支撑了 E2-5 的设计选择。
  • 性能维度：max-3 调度对本池 12 程序几乎免费，max-2 最差 +4.6%——若未来面向更小池或允许每池定制硬件，E2-2/E2-3 仍有价值（分池口径 BERT/SD-UNet 上 E2-2 更省）。
  • 未做（与 E2-5 相同）：28nm 门级时序签收、SAIF 功耗拆分、专用宏 PPA 对照——需商业工具环境。
